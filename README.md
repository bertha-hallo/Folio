# Bertha — Graphic Designer Portfolio

A modern, responsive portfolio website built with React and Vite, featuring a 3D flip ID card, GSAP animations, and an elegant warm aesthetic with Midnight Plum accents.

## Scripts

- `npm run dev` — start dev server
- `npm run build` — production build
- `npm run lint` — run ESLint
- `npm run preview` — preview production build

## Tech Stack

React 19 · Vite 8 · GSAP · ESLint

## Features

- Hero section with animated typography
- Interactive 3D flip ID card with lanyard swing
- Portfolio project gallery
- About section with autumn leaves background
- Fully responsive layout

## Getting Started

```bash
npm install
npm run dev
```
